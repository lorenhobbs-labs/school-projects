# Network Design Proposal

This folder contains my networking assignment work, including network design planning, device selection, subnetting, physical media choices, and security considerations.

## Project Overview

The purpose of this project is to design a network system using physical layer concepts and data link layer protocols. The project includes planning for switches, routers, wireless access points, network security devices, IP addressing, subnetting, and appropriate network media.

## Topics Covered

- LAN design
- Router and switch planning
- Wireless access point placement
- Physical media selection
- IP address class selection
- Subnet mask planning
- Network security devices
- OSI and TCP/IP model considerations

## Files

Planned files for this folder may include:

- Network design proposal document
- Network diagram
- Subnetting notes
- Device quantity estimates
- Final assignment submission
